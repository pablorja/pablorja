## Sobre mí

Soy desarrollador de software en formación, enfocado en construir APIs y aplicaciones que resuelvan necesidades concretas. Trabajo principalmente con **C# y ASP.NET Core**, y estoy ampliando mi experiencia creando interfaces y aplicaciones móviles con **Flutter**.

En mis proyectos practico el diseño de APIs REST, operaciones CRUD, persistencia en bases de datos relacionales e integración entre frontend y backend. Me gusta entender el flujo completo de una funcionalidad: desde el modelo de datos hasta la experiencia de quien usa la aplicación.
