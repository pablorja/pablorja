### Sobre mí

Soy desarrollador de software en formación, enfocado en crear APIs y aplicaciones que resuelvan necesidades concretas. Trabajo principalmente con **C# y ASP.NET Core**, y también desarrollo interfaces web y aplicaciones móviles con **Angular y Flutter**.

En mis proyectos practico el diseño de APIs REST, operaciones CRUD, persistencia en bases de datos relacionales e integración entre frontend y backend. Me interesa entender el ciclo completo de una funcionalidad: desde el modelo de datos hasta la experiencia de uso.

- 🎓 En formación continua en desarrollo de software
- 🧩 Experiencia práctica con C#, ASP.NET Core, APIs REST y CRUD
- 📱 Desarrollando aplicaciones Flutter y Dart
- 🗄️ Trabajando con PostgreSQL y MySQL
- 🎯 Busco una oportunidad junior o de prácticas para aportar y seguir creciendo
